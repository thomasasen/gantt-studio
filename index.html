Deine Projekt- und Planungsdaten bleiben in diesem Browser.

Gantt Studio besitzt auf GitHub Pages keine Projektdatenbank und keine Cloud-Synchronisierung. Für ein dauerhaftes Backup bitte regelmäßig exportieren.

Was bedeutet das genau?
Speicherung: Projekte liegen in IndexedDB dieses Browserprofils; nur die aktive Projekt-ID wird in localStorage gemerkt.
  • Es werden keine Projektinhalte an GitHub oder einen eigenen Gantt-Studio-Server übertragen oder dort gespeichert.
  • Die GitHub-Pages-Server liefern lediglich HTML, CSS und JavaScript der Anwendung aus.
  • Browserdaten löschen, ein anderes Gerät/Browserprofil verwenden oder privates Surfen kann dazu führen, dass lokale Projekte dort nicht verfügbar sind.
  • Beim optionalen Feiertagsimport wird Nager.Date direkt aus dem Browser abgefragt. Dabei werden Land und Jahr angefragt, nicht deine Projektinhalte.
